# 可迁移的表达功能

以下是研究中的候选模式，不是爆款因果规律。使用时要挂接本次确实已审的来源，按主题选择，不要求每条都有反转或强销售。

|任务|信息推进|自然承接|适用边界|
|操作教程|任务与验收 → 步骤 → 失败验证 → 修正 → 再验收|操作资产或下一节教程|必须完成实际测试；失败也可构成结果|
|专业教学|结果 → 判断标准 → 局部解释 → 扩展应用|同一技能的深入训练|专业标准不能被工具名替代|
|业务复盘|真实事件 → 决策 → 代价 → 使用结果 → 下一步|同类场景沟通或继续观察|不能借用对标的客户、数字和成功经历|
|简短方法|具体状态 → 对应动作 → 新状态|检查表或答疑|状态阈值需证据，不能复制未经核实的平台权重说法|
|观点表达|明确判断 → 机制/例证 → 条件 → 行动|关注或讨论|不必有领取资料/付费入口|

每卡写明开头许诺的收益在哪一段兑现，段落之间靠什么问题推进。画面、字幕、音效只在实际观看范围内记录；文字无法证明切镜频率。商业入口可见只能证明入口存在。
