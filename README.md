# 月明·对标研究

把多位创作者的作品与内容结构整理成有来源、可复用的研究材料，帮助判断哪些表达值得借鉴。

## 你会得到什么

- 研究范围与来源记录
- 开头承诺、段落功能、证据与适用条件组成的结构卡
- 账号内容排列分析、商业承接假设及证据缺口

## 试着这样说

```text
用 moonlit-benchmark-research。基于这批博主材料研究内容结构。把全文可用的样本和只有标题的样本分开，说明哪些结构适合我的受众。
```

## 安装与首次使用

将本仓库的完整目录交给支持本地 Skill 的 Agent 安装，保留 `SKILL.md` 与随附资源。已有同名版本时先检查差异；使用版本锁的工作区沿用自身升级机制。

让 Agent 安装：

```text
请安装这个 Skill：https://github.com/zzyong24/moonlit-benchmark-research
```

也可通过 Skills CLI 安装：

```bash
npx skills add zzyong24/moonlit-benchmark-research
```

## 配置与依赖

需要用户认可的研究范围、账号定位和已有材料。内容判断使用 moonlit-business-copywriter 的原则；取数缺口按需交给 redfox-intelligence。xuehui-short-video-methodology 仅在采用相应方法时读取。

## 数据与使用边界

查询会发送到所选信息源或数据服务。研究结果留在使用方研究目录；有正文才做全文结构分析，有画面才做视觉分析。点赞不能直接证明成交，研究不会自动创建作品或发布内容。
